# 点滴 · 多方案 Tweaks

从 `meiyou-diandi-jingqi` main 拉出的独立仓库。

## Tweaks

右下角 **方案 Tweaks**：方案 **A · 推荐** / A+ / **B · 推荐** / B+ / B++ / C / **D · 推荐**。

- **共享基线**：经期快捷「月经来了 / 走了」灰字引导、假键盘、收起平铺项、点空白收起、点输入框再弹起、发送后正文+标签（无经期感受水滴气泡）等。切换方案时输入框清空，且不默认弹起键盘。
- **差异位**：`html[data-scheme="A|A+|B|B+|B++|C|D"]`；面板里按当前方案显示专属 Tweaks 区。
  - **A（推荐）**：来了 → `量多还是少…`；走了 → `身体症状是…`
  - **A+**：来了 → `，流量是`；走了 → `，症状是`；光标停在「是」后
  - **B（推荐）**：胶囊输入 + 补充标签（逗号连接）
  - **B+**：同 B；`量有点少/量比较多`、`完全不痛/有点痛经` 成对互斥、同组替换
  - **B++**：接续式；点进只有「月经来了」；首组昨天来了／前天来了→经量→疼痛→颜色；左右滑换组；点句子回组
  - **C**：今天可点选 + 流量／颜色／痛经浮层；逗号连接（日期后无空格）
  - **D（推荐）**：前两项合并为「记经期」；点开彩色走马灯 + 短引导填入 A+ 句式；其余平铺项同其他方案

```js
// index.html
TWEAK_DEFAULTS = { demoScene, scheme: "B++" }

// 页面根节点
<html data-scheme="A|A+|B|B+|B++|C|D">
```
